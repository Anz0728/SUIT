# SUIT 새 UI

수어·음성으로 일상 대화를 이어가는 개인 사용자를 위한 모바일 우선 프론트엔드 데모입니다.

## 포함된 화면

- 홈과 상황 선택
- 카메라 수어 인식 체험
- 음성 인식 및 번역 확인
- 양방향 실시간 대화
- 자주 쓰는 표현과 대화 기록
- 접근성·언어·보관 설정
- 데모 관리 도구(설정 하단에서 열기)


## 참고

카메라는 기기 화면의 미리보기이며 수어 인식 결과는 선택한 예시 표현으로 체험합니다. 음성 인식도 예시 화면이며 실제 AI 서버에는 연결되어 있지 않습니다. 화면에 보이는 예시 확신도는 실시간 측정값이 아닙니다. 설정과 대화 기록은 현재 브라우저의 로컬 저장소에 보관됩니다.

## 공유용 웹 주소

`main` 브랜치에 변경 사항이 반영되면 `.github/workflows/deploy-pages.yml`이 GitHub Pages용 사이트를 빌드합니다. 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택해야 합니다. 배포가 완료되면 `https://anz0728.github.io/SUIT/`에서 볼 수 있습니다.
